## Option 1: Visual Studio 2022 Build Tools (RECOMMENDED)

### Why this option?

- ✓ Official Microsoft C++ compiler (MSVC)
- ✓ Best compatibility on Windows
- ✓ Fully integrated with CMake & Conan
- ✓ Project is configured for MSVC

### Steps:

1. **Download**: https://visualstudio.microsoft.com/downloads/
2. **Choose**: "Desktop development with C++"
3. **Install**: Follow the installer (10-15 minutes)
4. **Verify**: Open PowerShell and run:
   ```powershell
   cl
   ```

   Should show MSVC version info

### After Installation:

Your project is configured to use MSVC automatically. Just run:

```powershell
cd C:\Wrok_Zone\cpp-embedded-web-app
powershell -ExecutionPolicy Bypass -File .\build.ps1 build
```

## Option 2: MinGW-w64 (Lightweight)

### Why this option?

- ✓ Smaller download (~500 MB vs 2-4 GB)
- ✓ Uses GCC compiler
- ✓ No Visual Studio needed
- ✓ Good for portable installations

### Steps:

1. **Download**: https://www.mingw-w64.org/

   - Recommended: **w64devkit** (easiest to set up)
   - Alternative: MSYS2 environment
2. **Install**: Extract to a folder (e.g., `C:\mingw64`)
3. **Add to PATH**:

   ```powershell
   # Temporary (current session only):
   $env:PATH = "C:\mingw64\bin;" + $env:PATH

   # Permanent (all sessions):
   # Settings → Environment Variables → Path → Add C:\mingw64\bin
   ```
4. **Verify**: Open PowerShell and run:

   ```powershell
   gcc --version
   g++ --version
   ```

### After Installation:

Update Conan profile to use GCC:

```powershell
$conanProfile = "$env:USERPROFILE\.conan2\profiles\default"
$content = @'
[settings]
arch=x86_64
build_type=Release
compiler=gcc
compiler.version=11
compiler.cppstd=20
compiler.libcxx=libstdc++11
os=Windows
'@
Set-Content -Path $conanProfile -Value $content
```

Then build:

```powershell
cd C:\Wrok_Zone\cpp-embedded-web-app
powershell -ExecutionPolicy Bypass -File .\build.ps1 build
```

## Troubleshooting

### "Command not found: cl" (or gcc/clang)

- Compiler not installed or not in PATH
- **Solution**: Restart PowerShell after installation, or add to PATH manually
- Verify: `cl`, `gcc --version`, or `clang --version`

### "CMake Error: CMAKE_CXX_COMPILER not set"

- Compiler installed but not detected by CMake
- **Solution**:
  ```powershell
  # Add to PATH
  $env:PATH = "C:\path\to\compiler\bin;" + $env:PATH
  # Clean and rebuild
  rm build -Recurse -Force
  powershell -ExecutionPolicy Bypass -File .\build.ps1 build
  ```

### Build fails with "settings.compiler not defined"

- Conan profile is missing compiler settings
- **Solution**: This is now fixed! Profile has been updated.
- If still having issues:
  ```powershell
  py -m pip install --upgrade conan
  ```

### "Visual Studio 17 2022 generator not installed"

- Project configured for MSVC but Visual Studio isn't installed
- **Solution**: Either:
  - Install Visual Studio 2022 Build Tools (Recommended)
  - OR switch to MinGW-w64 and update Conan profile
